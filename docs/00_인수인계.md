## 📐 컨트랙트 핵심 설계 (변경 불가)

### 배포 순서 (deploy.ts 참고)

```
1. AFWToken
2. SOULToken
3. WorldMap
4. AgentRegistry
5. NodeRegistry
6. OracleGateway
7. EconomyEngine + QuestEngine
8. GovernanceDAO
→ 권한 설정 (ORACLE_ROLE, MINTER_ROLE 등)
```

### 권한(Role) 구조

```
AgentRegistry  ← ORACLE_ROLE: OracleGateway
SOULToken      ← MINTER_ROLE + BURNER_ROLE: EconomyEngine
EconomyEngine  ← QUEST_ROLE: QuestEngine
               ← COMBAT_ROLE: CombatResolver (미작성)
               ← MARKET_ROLE: Marketplace (미작성)
NodeRegistry   ← SLASHER_ROLE: OracleGateway
WorldMap       ← NODE_REGISTRY_ROLE: NodeRegistry
GovernanceDAO  ← ARCHITECT_ROLE: 기여자 (수동 부여)
```
