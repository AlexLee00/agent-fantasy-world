## 🔑 컨트랙트 핵심 구조 요약

### AFWToken.sol (완성)
```solidity
총 공급량: 1,000,000,000 AFW (고정)
배분: 노드40% + 커뮤니티25% + 팀15% + 생태계10% + 유동성5% + 어드바이저5%
mint() → revert (추가 발행 영구 불가)
burnForProtocol() → 수수료 소각
```

### SOULToken.sol (완성)
```solidity
공급량: 동적 (발행/소각 균형 유지)
발행: MINTER_ROLE만 가능, 일일 한도 있음
소각: BURNER_ROLE만 가능
getNetInflationBps() → 인플레이션 모니터링
```

### AgentRegistry.sol (완성)
```solidity
createAgent(class, personality[5]) → agentId
updateAgentState() → ORACLE_ROLE만 호출 가능
resolveMillestone() → 유저 개입 (Observer만)
_checkMilestone() → HP 20% 이하 시 자동 트리거
이벤트: AgentCreated, AgentLevelUp, MilestoneTriggered
```
